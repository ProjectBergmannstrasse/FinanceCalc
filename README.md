## How versions were numbered

Each step scored on impact against complexity, as you specified:

| | Low complexity | High complexity |
|---|---|---|
| **High impact** | +1.0 | +0.7 |
| **Medium impact** | +0.7 | +0.35 |
| **Low impact** | +0.5 | +0.2 |

High impact and easy earns a full point; intricate work that barely moved the
product earns 0.2. Builds adding no new capability step +0.2, or +0.5 where the
code grew more than 12%.
